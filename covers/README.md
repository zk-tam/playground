Put one frame per scene here, then run `python3 scripts/make-covers.py`.

Name each file after the scene's slug, the last part of its address:

    finals.webp
    the-best.webp
    theres-a-man-named-hershey.webp
    when-are-you-gonna-take-it.webp
    l-to-the-og.webp
    86-years.webp
    ill-take-ser-duncans-side.webp

A position in the list (`1.png`, `2.png`, ...) also works, but slugs stay right
when a scene is added in the middle.

PNG, JPEG, WebP, TIFF and HEIC all work. The originals are not changed.
